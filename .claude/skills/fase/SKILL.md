# Status da fase

1. Leia `docs/roadmap.md`. A fase atual é a primeira com 🟨.
2. Para cada item não marcado da fase atual, confira no código se já existe (busque pelo crate e pelos tipos citados) e se tem teste.
3. Responda com: fase atual, itens feitos, itens que faltam, e o que bloqueia o critério de saída.
4. Se o Kaique pedir para atualizar: marque `[x]` nos itens comprovados, troque o status da fase (⬜ → 🟨 → ✅) e passe a próxima para 🟨 quando a atual fechar. Nunca marque algo como feito sem prova no código ou na medição.
