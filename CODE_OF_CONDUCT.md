# Código de Conduta

## Nosso compromisso

Queremos que participar do SquadView seja uma experiência acolhedora para todo mundo, independentemente de idade, corpo, deficiência, etnia, identidade ou expressão de gênero, nível de experiência, nacionalidade, aparência, religião ou orientação sexual.

## O que esperamos

- Ser respeitoso e paciente, principalmente com quem está começando.
- Criticar ideias e código, nunca pessoas.
- Aceitar feedback construtivo com boa vontade.
- Pensar no que é melhor para a comunidade.

## O que não aceitamos

- Ofensas, assédio, piadas ou comentários discriminatórios.
- Ataques pessoais ou provocações.
- Publicar informações privadas de outras pessoas sem permissão.
- Qualquer conduta que seria inadequada num ambiente profissional.

## Aplicação

Casos podem ser reportados em particular para o mantenedor pelo GitHub ([@Kaique292](https://github.com/Kaique292)). Todas as denúncias são analisadas com sigilo. O mantenedor pode remover comentários, commits e contribuições, ou banir temporária ou permanentemente quem descumprir este código.
